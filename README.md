# repo1

## Структура репозитория
* `/src` - Исходный код проекта.
* `/data` - Данные (сырые и обработанные).
* `/notebooks` - Jupyter ноутбуки для экспериментов.
* `/docs` - Документация (план реализации, контракт данных, логи LLM).
* `/configs` - Конфигурационные файлы.
* `/tests` - Автотесты.
* `/scripts` - Вспомогательные скрипты для автоматизации.

## Быстрый старт (Windows)

Для автоматического создания Conda-окружения, установки зависимостей и проверки работоспособности выполните следующие шаги:

1. Откройте командную строку (cmd) или PowerShell.
2. Перейдите в корневую папку проекта.
3. Запустите скрипт автоматической настройки:
   ```cmd
   scripts\setup_env.bat
   ```
